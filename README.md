# GymBuddyAI

This repository contains a small React + Vite app for GymBuddyAI — a personal project.

**Personal Challenge:** This is a personal challenge for me to complete the project without AI-vibe code.

**About:**
- **Purpose:** Build a lightweight gym/fitness helper app using React and Vite.
- **Status:** In development.

**Installation:**

Install dependencies:

```bash
npm install
```

**Development:**

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

Lint the codebase:

```bash
npm run lint
```

**Tech stack:**
- **Framework:** React
- **Bundler / Dev server:** Vite
- **Linting:** ESLint

**Project structure (high level):**
- `src/` — React components and app entry (`main.jsx`, `App.jsx`, etc.)
- `public/` — static assets
- `index.html` — app shell
